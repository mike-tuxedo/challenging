LocalFirst App

Ihre datenschutzfreundliche, offline-fähige Anwendung

Jetzt im Browser öffnen Installationsanleitung

Warum LocalFirst?

🔒 Datenschutz

Ihre Daten bleiben auf Ihrem Gerät und werden nicht an Server übertragen.

📱 Offline-fähig

Nutzen Sie die App auch ohne Internetverbindung - Ihre Daten werden synchronisiert, sobald Sie wieder online sind.

⚡️ Schnell

Durch lokale Speicherung läuft die App blitzschnell und unabhängig von der Internetverbindung.

Installation

Installieren Sie die App auf Ihrem Gerät für den einfachen Zugriff:

Android (Chrome)

  1. Öffnen Sie die App in Chrome
  2. Tippen Sie auf das Drei-Punkte-Menü
  3. Wählen Sie "Zum Startbildschirm hinzufügen"
  4. Bestätigen Sie die Installation

iOS (Safari)

  1. Öffnen Sie die App in Safari
  2. Tippen Sie auf das Teilen-Symbol
  3. Wählen Sie "Zum Home-Bildschirm"
  4. Bestätigen Sie die Installation
